# @launchsim/adapters

`MarketAdapter` implementations. Math-mode adapters (`math/pump-curve`,
`math/cpmm`) ship first; a Surfpool chain-mode adapter follows once the math
mode has proven the demo (`docs/09-roadmap-mvp.md`).

Chain adapters are integration-tested rather than held to the 100% unit
coverage gate; their pure helpers are unit-tested at 100% (`docs/07`).
